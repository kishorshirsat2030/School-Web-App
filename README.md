# विद्यार्थी गुणपत्रक भरण्याचे अॅप

हे Streamlit अॅप तुमची विद्यमान `.xlsx` गुणपत्रिका थेट अपडेट करते. विद्यार्थ्याचे नाव व गुण सबमिट केल्यावर ते निवडलेल्या इयत्तेच्या आणि सत्राच्या शीटमध्ये लगेच जतन होतात. भरलेली गुणपत्रिका डाउनलोड करण्याचा पर्याय अॅपच्या तळाशी आहे.

## सुरू करा

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
py -m streamlit run app.py
```

अॅप `Documents\PAPA\ZPPS Malegaon.xlsx` ही फाइल वापरते. अॅप ज्या संगणकावर चालते, त्या संगणकावर ही Excel फाइल असणे आवश्यक आहे. दुसऱ्या ठिकाणची फाइल वापरायची असल्यास PowerShell मधून `ZPPS_WORKBOOK_PATH` पर्यावरण चल सेट करा:

```powershell
$env:ZPPS_WORKBOOK_PATH = "C:\path\to\your\ZPPS Malegaon.xlsx"
py -m streamlit run app.py
```

अॅपमध्ये इयत्ता, सत्र आणि हजेरी क्रमांक निवडा, नाव व गुण भरा आणि **Excel मध्ये जतन करा** दाबा. प्रत्येक हजेरी क्रमांकासाठी ओळी 10–29 वापरल्या जातात. पहिल्या सत्रासाठी नाव B स्तंभात व गुण C–I/K–M मध्ये; दुसऱ्या सत्रासाठी नाव W स्तंभात व गुण X–AD/AF–AH मध्ये जतन होतात. भरलेली संपूर्ण गुणपत्रिका तिची सूत्रे व लिंकसह डाउनलोड करण्यासाठी पृष्ठाच्या तळाशी **Excel गुणपत्रिका डाउनलोड करा** दाबा. एकूण गुण व श्रेणीची सूत्रे अॅप बदलत नाही; Excel मध्ये फाइल उघडल्यावर ती पुन्हा गणना होतील.

गुणपत्रिका अॅपमध्ये वापरताना Excel मध्ये उघडी ठेवू नका. अॅप थेट मूळ फाइल जतन करते; आधी तिची बॅकअप प्रत ठेवणे उचित आहे.
